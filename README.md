# Wizard Hub

ระบบหลังบ้านกลางของ Wizard Auto Care สำหรับจัดการบริการ ราคา สาขา โปรโมชั่น FAQ Business Rules และงาน Call Center จากที่เดียว

- [docs/design.html](docs/design.html): Blueprint ของระบบ
- [demo/](demo/): เดโมแบบกดใช้งานได้ ใช้ข้อมูลตัวอย่าง เปิดไฟล์ `demo/index.html` ผ่าน web server (เช่น `npx serve demo`)

สถานะ: ช่วงออกแบบและเดโม ยังไม่เชื่อม LINE OA, AI Voice, Odoo, SIP หรือ AWS
